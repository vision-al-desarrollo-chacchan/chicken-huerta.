# Chicken Huerta

Página web y carta digital de Chicken Huerta, con pedidos por WhatsApp y administración de catálogo.

El código procede de la versión publicada el 18 de octubre de 2026. El despliegue independiente en Cloudflare requiere configurar D1, R2 y sustituir la autenticación de administrador de ChatGPT antes de habilitar el panel.
